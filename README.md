# Пепел между кадрами

Пиксельная аркадная action-RPG для ПК и телефона. Мир стирается из истории из-за Нулевой Свечи.
Рен, Последний Смотритель, умеет ненадолго возвращать вещам и врагам их прошлое — **Отпечаток** —
вместо **Шрама**, которым они стали после Стирания.

**Играть:** https://antonlabukhin-hue.github.io/ash-between-frames/

## Что есть в прототипе
- Глава 1 «Колокол, который не помнит удара»: Затухший тракт → Разорванная дорога → Чужой привал →
  Площадь без центра → Лестница из двух версий → Звонкая Тень → Подъём к колокольне → Брат Мел → выбор.
- Убежище «Кухня Последнего Дня»: печь (улучшения), стол (вылазки в Пепельные руины), спасённые NPC.
- Бой: удар → связка → разлом (окно точности на клинке), уклонение с «Окном Эха», импульсный разлом.
- Двойной отпечаток: мост, камень памяти, фонари, костёр, лестницы, статуя, колокол, враги и даже снаряды.
- Управление: клавиатура+мышь, геймпад, сенсорные кнопки; упрощённый режим с автоударом.
- Сохранение после каждой комнаты, настройки звука/вибрации/кнопок.

## Управление (ПК)
WASD — движение · ЛКМ/J — удар · ПКМ/Shift — уклонение · Q — сменить состояние ·
E — взаимодействие · Пробел — разлом · Esc — пауза

## Разработка
```
npm install
npm run dev        # http://localhost:5310
npm run test:unit  # vitest
npm run build      # dist/
```
Внутреннее разрешение 384×216, nearest-neighbor; вся графика и звук генерируются кодом.
