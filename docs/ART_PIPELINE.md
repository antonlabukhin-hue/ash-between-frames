# Гибридный конвейер арта

Код рисует то, что живёт и меняется: свет, отражения, дождь, туман, частицы, вспышки
ударов, переходы прошлое/настоящее, подсветку и таблички. Нарисованное (художником или
генератором) — то, что требует тысяч уникальных деталей: пол и стены комнат, позже —
крупные объекты и персонажи. Если рисованного слоя нет, работает кодовый маляр, так что
игру можно наполнять постепенно, комната за комнатой.

## Слои комнаты

| Слой | Что на нём | Прозрачность |
|---|---|---|
| `floor` | пол, дорога, стены, низкий декор, провалы | небо и пустоты вырезаются по маске шаблона |
| `over` | то, что поверх персонажей (кроны, передний план) | фон рисуется чистой маджентой `#FF00FF`, она вырезается |

У каждого слоя — две фазы: `present` (Шрам) и `past` (Отпечаток, проступает в островах памяти).
Объекты (деревья, фонари, знамёна, сундуки, башни) — отдельные спрайты игры, на фоне их не рисуют.

## Шаги

1. **Шаблон.** `node scripts/art-template.mjs road` → `art/templates/road/`:
   `reference.png` (комната как сейчас), `guide.png` (сетка, стены, провал, выход, подписи
   объектов), `mask.png` (проходимость), `spec.json` (размеры). Размер картинки — комната
   в плотной сетке (тракт — 960×1472, тайл 32 px).
2. **Задание.** Текст запроса — `art/prompts/<имя>.md` (пример: `road-floor.md`): вид сверху 3/4
   без перспективы, пропорции комнаты, что рисовать и чего не рисовать, стиль и палитра.
3. **Генерация.** `node scripts/art-gen.mjs all art/prompts/road-floor.md --n 2 --ref art/templates/road/reference.png`
   → `art/inbox/road-floor/gemini-1.png`, `grok-1.png`… Ключи — в `.env.local` (в git не попадает):
   ```
   GEMINI_API_KEY=...
   XAI_API_KEY=...
   ```
   Модели меняются переменными `GEMINI_IMAGE_MODEL`, `XAI_IMAGE_MODEL`.
4. **Согласование.** Claude показывает варианты, вы выбираете, просите правки (новый запуск
   с уточнённым заданием) или отклоняете. Без вашего «да» ничего не попадает в игру.
5. **В игру.** `node scripts/art-approve.mjs art/inbox/road-floor/gemini-1.png road floor present`:
   масштаб к комнате, вырез неба и пустот, 15-битный цвет с дизерингом, чёткий край →
   `public/art/rooms/road/floor-present.png` и запись в `public/art/rooms/manifest.json`.
6. **Проверка.** Контрольные кадры `node scripts/shots32.mjs <стадия>`, тесты, деплой.

Для шагов 1, 3, 5 и 6 нужен запущенный dev-сервер (`ABF_URL`, по умолчанию :5310).

## Какие ИИ подходят

| Сервис | Картинки через API | Ключ |
|---|---|---|
| Gemini (Google) | да — модели «Nano Banana» / Gemini Image | aistudio.google.com → API key |
| Grok (xAI) | да — Grok Imagine | console.x.ai → API key |
| DeepSeek | нет (официальный API — только текст) | можно для текста заданий, не для рисунков |

Подписка в приложении (Gemini, SuperGrok) не даёт доступа к API — ключ и оплата API отдельные.

## Ограничения генераторов

- Держат композицию, но не сетку: проходимость сверяется по шаблону, при сдвигах — повторная
  генерация с `--ref` или ручная правка.
- Не умеют прозрачность — поэтому маска для пола и маджента для переднего плана.
- Плохо держат одного персонажа от кадра к кадру: анимации героя и врагов остаются за кодом
  или художником.
