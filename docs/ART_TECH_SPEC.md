# ART_TECH_SPEC — 32-битный пиксель-арт

Направление: ночная dark fantasy в духе поздних 2D-игр 32-битной эпохи — плотная пиксельная
сетка, светотень градиентами внутри чёткого силуэта, цветной свет, мокрый камень, дождь и туман.
Без 3D-моделей. Всё рисуется кодом и запекается; в кадре — только `drawImage` из кэшей.
Эталон — Затухший тракт (`src/art/road32.js`).

## 1. Кадр и сетка

| Параметр | Значение |
|---|---|
| Мир | логические пиксели, тайл 16×16 — игровая логика не менялась |
| Холст | в `RS = 2` раза плотнее мира (`src/core/frame.js`), контекст — `scale(RS)` |
| Кадр мира | высота 180–270 (цель 240), ширина 320–512 по соотношению сторон |
| Масштаб к экрану | целый в физических пикселях, если закрывает ≥ 92 % экрана (почти всегда); иначе дробный «вписанный» — без пустых полей |
| Позиции | камера и спрайты — с шагом 1/RS пикселя мира (движение вдвое плавнее) |
| Фильтрация | ближайший сосед для спрайтов и комнат; свет, туман, виньетка — сглаженно |

Примеры: 1920×1080 → 480×270 ×2; телефон 844×390 @3 → 422×194 ×3; 1280×720 → 320×180 ×2.

## 2. Как рисуется кадр

- **HD-маляр** (`src/art/hd.js`): форма — многоугольники и эллипсы в плотной сетке, объём —
  градиенты (свет луны сверху слева), детали с шагом 1/RS. Затем атлас **пикселизует** кадр:
  альфа без полутонов (чёткий край) и цвет 15 бит с дизерингом Байера 4×4. Контур — 1 пиксель
  плотной сетки.
- **Старые 16-битные маляры** (ещё не переписанные NPC, Брат Мел, Звонкая Тень, часть объектов)
  рисуют в логических пикселях; кадр удваивается **Scale2x** — лесенки становятся ровными
  наклонами без новых цветов.
- **Комнаты**: обычные — набор тайлов `src/art/tiles32.js` сразу в плотной сетке (каждый вид
  пола — сплошная текстура по своей области); со своим маляром — `def.paint` (логические
  пиксели, Scale2x) + `def.paintHd` (плотная сетка поверх).
- Включатель: `src/art/hdflag.js` (`hd.on = false` — прежние кадры через Scale2x).

## 3. Свет

- Тьма — слой в половинном разрешении, мягкие радиальные маски, растягивается сглаженно;
  оттенок холодный лунный (`rgba(6,10,30,…)`).
- Цветной свет — сложением цветов: пятно на земле (эллипс в перспективе) под источником,
  ореол и яркое ядро у огня, мерцание живого огня. Источник знает цвет (`lightColor` по фазе)
  и высоту (`lightY`); у комнаты могут быть постоянные источники (`def.lights`).
- Цвета: янтарь/огонь — прошлое и живой огонь, малиновый — Стирание, бирюза — браслет,
  холодный — луна и Шрам.
- Число источников ограничено профилем, лишние гасятся по удалённости от героя.

## 4. Погода комнаты (`def.weather`, `src/art/atmo.js`)

| Поле | Что |
|---|---|
| `rain` | плотность дождя 0..1 (доля от лимита профиля): тонкие струи в плотной сетке, всплески |
| `wet` | коды мокрых тайлов (по умолчанию дорога, брусчатка, плиты, ступени): отражения огней полосами с рябью, на High — перевёрнутые отражения героя и врагов |
| `fog`, `fogA` | цвет и плотность тумана — два слоя клубов с разной скоростью |
| `leaves` | падающие листья |
| `wind` | наклон струй |

Виньетка — во всех профилях.

## 5. Профили качества

| | Low | Medium | High |
|---|---|---|---|
| Цветные ореолы (bloom) | — | да | да |
| Отражения (`reflect`) | — | огни | огни + персонажи |
| Струй дождя | 50 | 110 | 180 |
| Туман | — | да | да |

Читаемость боя одинакова во всех профилях: телеграфы, метки, полоски здоровья и подсказки
рисуются поверх света и погоды.

## 6. Палитра

Цвет больше не ограничен 48 оттенками: градиенты внутри формы сводятся к 15 битам. Смысловые
цвета прежние — янтарь (прошлое), малиновый (Стирание и опасность), бирюза (магия), здоровье
героя — молочно-янтарное (не красное).

## 7. Прошлое и настоящее

Каждый важный объект различается сразу по четырём признакам: форма, палитра, анимация, звук.
Переход между состояниями — прежняя 8-кадровая последовательность.

## 8. Запрещено

3D-модели; размытие спрайтов и комнат (мягкими бывают только свет, туман и виньетка);
постоянный CRT-фильтр; огромные фоновые текстуры; динамический свет на каждый объект.
