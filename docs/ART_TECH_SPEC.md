# ART_TECH_SPEC — Enhanced 16-bit / 2.5D Pixel Art

Направление: дорогая современная инди action-RPG в духе лучших 16-bit игр Sega, без 3D-моделей,
без случайных pixel-art фильтров и без постоянных пост-эффектов. Всё рисуется кодом в пиксельной
сетке и запекается в атласы.

## 1. Кадр и масштаб

| Параметр | Значение |
|---|---|
| Внутренняя высота | 208–240 px (цель ≈ 224) |
| Внутренняя ширина | 320–448 px (по соотношению сторон экрана) |
| Масштаб | **только целый**, считается в физических пикселях устройства (`devicePixelRatio`) |
| Фильтрация | Nearest Neighbor везде: холст, атласы, CSS `image-rendering: pixelated` |
| Сетка | тайл 16×16; крупные объекты 32×32, 32×48, 48×48 |
| Камера | вид сверху 3/4, позиции округляются до целого пикселя перед отрисовкой |

Подбор кадра: `s = round(физическая высота / 224)`, затем `H = физическая высота / s` (обрезка до 208–240),
`W = физическая ширина / s` (320–448). Лишнее — тёмные поля, никакого дробного масштаба.

## 2. Палитра

Ограниченная палитра (≈ 48 цветов на сцену). Цвет никогда не единственный признак состояния.

| Группа | Цвета | Где |
|---|---|---|
| Нейтральный город | сине-чёрный, холодный синий камень, серо-фиолетовая земля, приглушённый серый, тёмная бронза, выцветшее дерево | тайлы, стены |
| Прошлое (Отпечаток) | янтарь, охра, тёплый кирпич, приглушённое золото, крем для бликов, умеренный зелёно-синий | переключённые объекты, свет фонарей |
| Настоящее (Шрам) | бордо, тёмный фиолетовый, малиновый, чёрно-синий, грязный серый, редкие бело-серые пустоты | разломы, опасность |
| Магия/лечение | бирюза | браслет, лечение, подсказки |
| Здоровье героя | молочно-янтарное | не красное — красный занят опасностью |

## 3. Спрайты

- Герой и враги — покадровая анимация с фиксированным числом кадров: ходьба 6, удар 5, уклонение 4,
  смена состояния 6 + вспышка, смерть 6 (рассыпание на квадраты).
- Каждый кадр запекается в атлас один раз; в бою только `drawImage` из атласа.
- Персонажи получают **тёмный контур в 1 px** (selout) при запекании — герой читается на любом фоне.
- Освещение спрайта: 3 тона на материал (тень, основа, блик) + 1 px рим-свет со стороны источника.

## 4. Прошлое и настоящее

Каждый важный объект различается сразу по четырём признакам: **форма, палитра, анимация, звук**.

- Отпечаток: ровные края, симметрия, плавные циклы анимации, тёплые блики, пыль и искры.
- Шрам: рваные края, пропущенные пиксели, малиновые трещины, зависшие обломки, рывки кадров (пропуск каждого третьего).

Переход между состояниями — единая 8-кадровая последовательность (≈ 0,27 с):
янтарный контур → двойной контур → сдвиг старой версии на 1 px → малиновые трещины →
кадр с потерей деталей → новая версия → короткий след → звук фиксации. Переход не закрывает героя и опасные зоны.

## 5. Свет

- Базовый свет холодный сине-серый; слой тьмы в половинном разрешении.
- Источники — **ступенчатые пиксельные маски** (3–4 кольца, без мягких градиентов), запекаются в кэш по радиусу.
- Янтарные ореолы прошлого — геометрические пятна на земле; малиновые разломы подсвечивают только ближайшие пиксели.
- Число источников ограничено профилем качества; лишние гасятся по удалённости от героя.

## 6. Параллакс

Над северной стеной комнаты — полоса неба с 1–3 слоями (дальний горизонт, подвешенная колокольня, ближние обломки).
Скорость слоёв 0,15 / 0,3 / 0,5 от камеры. Слои — тайлящиеся полосы шириной 256 px, не огромные текстуры.

## 7. Частицы

Только квадратные пиксели 1×1 и 2×2 из пула фиксированного размера. Никакого размытия и сложения цветов.
Постоянный фон частиц (пепел) — не больше 50 на High.

## 8. Интерфейс

Пиксельный HUD на холсте (здоровье, браслет, разлом, способности), текст — HTML-слой с пиксельным
шрифтом Pixelify Sans (кириллица), размер не меньше 12 CSS px на телефоне.

## 9. Запрещено

3D-модели и 3D-персонажи; pixel-art фильтр поверх рендера; размытие; постоянный bloom и CRT; огромные
фоновые текстуры; сотни частиц; динамический свет на каждый объект; дробный масштаб.
