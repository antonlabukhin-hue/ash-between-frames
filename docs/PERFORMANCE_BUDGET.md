# PERFORMANCE_BUDGET

Цель: стабильные 60 FPS на современных средних телефонах, отдельный режим 30 FPS для слабых,
без просадок в бою с боссом, быстрая загрузка комнаты, умеренная память и без перегрева.

Эталон «средний телефон» для замеров — настольный Edge с замедлением CPU ×4 (CDP `Emulation.setCPUThrottlingRate`).

## 1. Бюджет кадра (60 FPS = 16,7 мс)

| Часть | Medium | Low | Примечание |
|---|---|---|---|
| Логика (`game.update`) | ≤ 3 мс | ≤ 3 мс | враги, снаряды, частицы, сценарий |
| Отрисовка (`renderWorld`) | ≤ 5 мс | ≤ 3,5 мс | на эталоне CPU ×4 |
| Итого CPU | ≤ 8 мс | ≤ 6,5 мс | остаток — браузер, композиция, запас на GC |
| Режим 30 FPS | — | рендер каждый 2-й кадр | логика всё равно с шагом ≤ 50 мс |

## 2. Лимиты на кадр по профилям

| Лимит | Low | Medium | High |
|---|---|---|---|
| Вызовы отрисовки (fillRect + drawImage на основном холсте) | ≤ 250 | ≤ 400 | ≤ 650 |
| Частицы (пул) | 80 | 200 | 360 |
| Фоновые частицы (пепел) | 0 | 20 | 45 |
| Источники света | 4 | 8 | 14 |
| Кольца в маске света | 2 | 3 | 4 |
| Слои параллакса | 1 | 2 | 3 |
| Полноэкранные прозрачные слои | 1 | 2 | 2 |
| Анимация декора | статичная | обычная | + декоративные циклы |
| Тени персонажей | плоская полоса | ступенчатый эллипс | ступенчатый эллипс |
| Сбои кадра (глитч) | выкл. | редкие | редкие |
| Активные враги одновременно | ≤ 12 во всех профилях |||

Читаемость не зависит от профиля: телеграфы атак, контуры, полоски здоровья и подсказки одинаковы везде.

## 3. Память

| Ресурс | Лимит |
|---|---|
| Атласы спрайтов | 2 страницы × 1024×1024 RGBA ≈ 8 МБ |
| Холст комнаты (запечённые тайлы) | ≤ 1024×1024 ≈ 4 МБ, комнаты больше — по чанкам 512×512 |
| Слой света | половина кадра ≈ 0,1 МБ |
| Кэш масок света | ≤ 24 масок ≈ 0,5 МБ |
| Куча JS | ≤ 60 МБ в обычной сессии |

## 4. Загрузка

- Запекание комнаты ≤ 100 мс на эталоне; спрайты печатаются в атлас лениво при первом показе
  и прогреваются для врагов комнаты при входе.
- Шрифт и код — один бандл ≤ 200 КБ gzip; звуки синтезируются, файлов нет.

## 5. Приёмы оптимизации

- **Атласы**: каждый кадр персонажа/объекта рисуется кодом один раз, потом только `drawImage`.
- **Пул частиц**: фиксированный массив, без `push/shift/filter` в горячем цикле.
- **Отсечение**: объекты вне камеры (+ поле 32 px) не рисуются; частицы вне кадра не рисуются.
- **Дальний AI**: враги дальше 1,5 экрана думают раз в 4 кадра (с накопленным dt), снаряды вне 2 экранов удаляются.
- **Логика объектов вне камеры**: декоративные анимации и пульсы фонарей вне кадра не считаются.
- **Повторное использование тайлов**: тайлы печатаются в общий тайлсет-кэш по (тип, вариант), комната собирается копированием.
- **Кэш эффектов**: маски света и кольца перехода запекаются по радиусу.
- **Прозрачность**: не больше двух полноэкранных полупрозрачных слоёв (свет + вспышка урона).
- **Автопрофиль**: в режиме «Авто» среднее время кадра > 20 мс три секунды подряд понижает профиль на ступень.

## 6. Отладочный оверлей

`F3` или `?debug`: FPS, время кадра (логика/отрисовка), объекты, частицы, вызовы отрисовки,
память (куча JS и холсты), активные источники света, активные враги, профиль.

## 7. Замеры (2026-10-18, Edge, CPU ×4, кадр 448×234 ×5 — телефон 19.5:9)

`node scripts/perf.mjs <комната> 4 <профиль> [здоровье босса]` — 8 с боя, герой бьёт и уклоняется, волны врагов.

| Сцена | Профиль | FPS | Кадр макс | Логика | Отрисовка | Вызовы ср./пик |
|---|---|---|---|---|---|---|
| Площадь без центра, бой | Low | 59.7 | 33 мс | 1.6 мс | 3.5 мс | 153 / 216 |
| Площадь без центра, бой | Medium | 59.9 | 17 мс | 1.5 мс | 4.2 мс | 182 / 252 |
| Площадь без центра, бой | High | 59.9 | 33 мс | 1.5 мс | 3.8 мс | 224 / 350 |
| Брат Мел, фаза 1 | Medium | 59.9 | 17 мс | 1.0 мс | 3.1 мс | — |
| Брат Мел, фаза 2 | Medium | 59.9 | 17 мс | 1.0 мс | 2.7 мс | 77 / 160 |
| Брат Мел, фаза 3 | Medium | 59.9 | 18 мс | 1.0 мс | 2.7 мс | — |

До перехода на атлас (тот же бой, Medium): 47 FPS, отрисовка 9.3 мс, 470 вызовов.
Единичные кадры 33 мс — первое запекание новых кадров в атлас; дальше кадры берутся из кэша.

Главные выигрыши: атлас спрайтов (−60 % отрисовки), HUD слоем и цифры из атласа (−100 вызовов),
кольца волн из заготовок (было до 600 вызовов на волну), поле пустоты одним узором (−200 вызовов на арене).
