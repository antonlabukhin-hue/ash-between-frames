# SPRITE_PIPELINE

Все спрайты рисуются кодом в пиксельной сетке и запекаются в атласы. Внешних картинок нет.

## 1. Источник

Функция рисования `draw*(ctx, x, y, opts)` в `src/art/sprites.js`, `src/world/props.js`, `src/art/level01.js`.
Координаты — точка ног (низ-центр). Цвета — только из палитры `src/art/palette.js`.

## 2. Кадры

Перед запеканием параметры анимации **квантуются**:

| Анимация | Кадров | Как квантуется |
|---|---|---|
| Ходьба героя | 6 | `walk` → `floor(walk × 6) / 6` |
| Колыхание плаща | 3 | `sway` → −1 / 0 / +1 × 2,5 |
| Удар героя | 5 | время взмаха → 0…4 |
| Прицел/меч | 8 направлений | угол → шаг 45° |
| Время у декора | 4–8 | `t` → кадр цикла |
| Враги | 4–6 | фаза ходьбы/подготовки |

Ключ кадра — строка из имени спрайта и квантованных параметров, например `hero|down|w3|s0|a2|sw-|g0|c3`.

## 3. Атлас (`src/art/atlas.js`)

- Страницы 1024×1024, укладка полками (shelf packing) с отступом 1 px.
- `atlas.sprite(key, w, h, ax, ay, draw, { outline })` — если кадра нет, выделяет место, рисует и
  запоминает; возвращает запись `{ page, sx, sy, w, h, ax, ay }`. Отрисовка — один `drawImage`.
- Варианты: обычный, белая вспышка попадания, контур фазы (янтарь/малина) — отдельные ключи.
- Автоконтур: после рисования по маске альфы добавляется тёмный контур 1 px (selout) — для персонажей и врагов.
- Переполнение: при заполнении всех страниц атлас очищается целиком (LRU по комнатам не нужен —
  комната прогревает свои кадры при входе).
- Статистика для оверлея: число кадров, занятость страниц, память.

## 4. Тайлы

Тайлы печатаются в тайлсет-кэш по `(тип, вариант 0..7)`, комната собирается копированием тайлов
на холст комнаты (один `drawImage` на кадр). Варианты выбираются хешем координат — без шума и повторов «шахматкой».

## 5. Проверка

- `?sprites` — лист спрайтов крупно; `node scripts/sprite-shot.mjs`.
- `node scripts/shots.mjs square` — эталонная комната в 3×; `node scripts/mobile-shots.mjs` — телефон.
- Правило приёмки: силуэт героя читается за секунду на любом тайле; враги различимы по силуэту без цвета.
